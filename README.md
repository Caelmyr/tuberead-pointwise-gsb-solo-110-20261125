# TubeRead 量筒读数台

给正放、平视拍摄的量筒照片做体积读数。适用于可见凹液面，以原片左上作为坐标零点，Y 向下。默认在现有两处已知参考刻度之间线性估读；也可填入相邻短刻线的毫升档值，识别并保存右壁实拍中间线，用液位实际夹在的两条已认刻线分段估读。

1. 打开明确注明合成的练习量筒，或者导入一张单帧 PNG、JPEG、TIFF、BMP 或 WebP。
2. 填量筒左右壁、上和下刻度的原片 Y 及实际体积。点原片查看亮度和对应的刻度范围，或打开「取液位」后点凹液面中央的底部。
3. 若中间刻线间距在片上不完全均匀，再填「每档 mL（相邻短刻线）」，点击「识别中间刻线并采用实线」。识别只使用右壁两侧各一成筒内宽的横笔窄带，每档在两端粗分位置上下 3/4 格距内匹配；档号从上到下一对一，未认到的档留空，至少两条中间线才会采用。
4. 保存后核对当前体积、液位横行的实际亮度剖面，以及校样中高亮的夹读实线。点读、重新打开卡片、CSV 和 PNG 校样使用同一份已保存 Y 坐标；跨过未认档时会标明实际使用的两条线。也可用「原两点读法」切回两端均分。
5. 超出所设的两个已知参考刻度时不外推体积。然后下载带真实源坐标的 PNG、CSV 或读数 ZIP，或把原照片送去照片准备。

`docker compose up --build -d --wait` 默认监听本机 19913。也可在 Python 3.11 虚拟环境安装 `requirements.txt` 后运行 `./start.sh`。数据保存在 Compose 独立卷或普通启动的本地数据目录。
