# TubeRead 量筒读数台

给正放、平视拍摄的量筒照片做体积读数。适用于可见凹液面，以原片左上作为坐标零点，Y 向下。在现有两处已知参考刻度之间线性估读。

1. 打开明确注明合成的练习量筒，或者导入一张单帧 PNG、JPEG、TIFF、BMP 或 WebP。
2. 填量筒左右壁、上和下刻度的原片 Y 及实际体积。点原片查看亮度和对应的刻度范围，或打开「取液位」后点凹液面中央的底部。
3. 保存并重读，核对当前体积和液位横行的实际亮度剖面。然后下载带真实源坐标的 PNG、CSV 或读数 ZIP，或把原照片送去照片准备。
4. 已保存的卡片可从下拉菜单重新打开。超出所设的两个参考刻度时不外推体积。

`docker compose up --build -d --wait` 默认监听本机 19913。也可在 Python 3.11 虚拟环境安装 `requirements.txt` 后运行 `./start.sh`。数据保存在 Compose 独立卷或普通启动的本地数据目录。
